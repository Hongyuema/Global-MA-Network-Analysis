# Two-star matrices

This folder contains GDP-adjusted partial-correlation matrices and pairwise complete-case sample-size matrices generated by `R/03_compute_two_star_partial_correlation.R`.

Naming convention:

```text
OWID_item_partial_correlation_<YEAR>_GDPcontrolled_min30.csv
OWID_item_partial_pairwise_n_<YEAR>_GDPcontrolled_min30.csv
```
